# CHL5233 Week 2 In-class Assignment

Introduction to Git, GitHub, R, and Positron using the `yrbss` data from the `openintro` package.

## Files

- `01-inclass.R`: R script for the in-class assignment
- `renv.lock`: R package versions used in this project

## How to reproduce

1. Clone this repository and open the folder in Positron.
2. Run `renv::restore()` in the R console to install the required packages.
3. Run `01-inclass.R`.
